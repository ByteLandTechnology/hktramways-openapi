# Security Policy

## Scope and Responsibilities

Understand the difference between this repository and the official API:

1. **This Repository (`ByteLandTechnology/hktramways-openapi`)**:
   - This repository holds build scripts, documentation files, and npm packages.
   - We maintain the security of these local repository files.

2. **Official Server (`api.hktramways.com`)**:
   - This project has no connection to Hong Kong Tramways, Limited.
   - Do not open a public issue here if you find a problem on `api.hktramways.com`.
   - Report problems on `api.hktramways.com` directly to Hong Kong Tramways, Limited.

---

## Report a Security Problem in This Repository

Follow these instructions to report a vulnerability in this repository:

1. Do not open a public GitHub issue.
2. Report the vulnerability through [GitHub Security Advisories](https://github.com/ByteLandTechnology/hktramways-openapi/security/advisories/new).
3. Give detailed steps to reproduce the problem.
4. Include any suggested solution.

We will reply within 48 hours and release a fix as soon as possible.
